## 文件內容摘要

**`804592428-梁烱輝-臺灣閩南語傳統語文教育文讀音系統之調查與研究.pdf`**

論文第二章說明：附表一共 84,723 筆「發音人單字語音」；聲母用的是作者所稱的 「TLPA」臺語音標；右上角兩位數字是**實際調值**，不是**調序**。要對傳統韻書／本調，作者叫人去查 附表三。


| 項目 | 附表一（D-1～D-298） | 本專案字典需要的 |
|---|---|---|
| 內容 | 7 位以上發音人的單字實錄 | 漢字 → 一個（或少數）讀音碼 |
| 規模 | 約 298 頁、84,723 筆 | 去重後約數千字（文讀字表） |
| 羅馬字 | 論文用 TLPA（`c`/`ch`/`kh`/`oo`） | `ji_khoo_tl` 是台羅（`ts`/`tsh`）；`ji_khoo_bpm2` 是注音二式 |
| 聲調 | 調值 `³³` `⁵³` `¹¹`… | 調號 `1`～`8` |
| `#` | 正文凡例：語流段落（常是連讀／變調） | 字典應收本調，不宜直接當編碼 |
| 檔案 | 掃描件、無內嵌文字 | 機器可解析的 `漢字\t讀音\t權重` |
適合當來源，原因

欄位已是「漢字 + 羅馬字」，方向對。
論文聲母對十五音有對照，例如邊 [p]、頗 [ph]、時 [s]、入 [j]、地 [t]、他 [th]、柳 [n]/[l]、求 [k]、去 [kh]、語 [ng]/[g]。
這是 文讀音 調查，和十八音／漢文誦讀的目標一致，不是白話辭典。

## 需求

【附表三】，自 Page: D-403 開始，於 D-5000 結束。

取用附表資料，製作【中州韻字典檔】： `xyz.dict.yaml` 。

 1. 漢字：取自【單字出現次數】欄，如：【蓬0003】，只取【蓬】。

 2. 漢字標音：取自【發音人文讀音（聲調取調值）】欄：

    - 漢字標音採用【台羅拼音】，故遇以下狀況，需轉換：
      【聲母】
        - ch ==> tsh
        - c ==> ts

    - 調號：上標調值掃描太小，OCR 讀不到；依你寫的「調值有意外則用十五音聲調」，本試作 全部用彙集雅俗通聲調（上平1、上上2、上去3、上入4、下平5、下去7、下入8）
