#### 作業程序

1. 開啟【甘字典】Excel 檔案，選擇【RIME】工作表。
2. 自【RIME】工作表，讀取一列（Row）的資料，寫入【甘字典漢字庫】資料庫的【漢字庫】資料表：
   - 【A欄】：text ==》 資料表【漢字】欄
   - 【B欄】：code ==》 資料表【台羅音標】欄
   - 【C欄】：weight ==》 資料表【常用度】欄
   - 【D欄】：stem ==》 資料表【摘要說明】欄
3. 在 Console 顯示目前已完成處理的：列號、漢字、台語音標；
4. 重複步驟 2，直至工作表所有列均已寫入【漢字庫】資料表。

【甘字典漢字庫】之資料庫建置，請參考後面章節之《甘字典漢字庫》說明。

### 自資料庫匯出到中州韻字典檔流程

將資料庫之資料匯出，用以建置【中州韻字典檔】（RIME Dict: xxx.dict.yaml）。

1. 建立中州韻字典檔的【檔頭】(Header)；
2. 開啟【甘字典漢字庫】資料庫。
3. 自【漢字庫】資料表讀取一筆資料紀錄，寫入中州韻字典檔的【檔身】(Body)；
   - 【漢字】欄 ==》 text
   - 【台羅音標】欄 ==》 code
   - 【常用度】欄 ==》 weight
   - 【摘要說明】欄 ==》 stem
   - 【時間戳記】欄 ==》 create
4. 重複步驟 3，直至【漢字庫】資料表所有的資料紀錄，均已寫入【中州韻字典檔】的【檔身】；
5. 儲存【中州韻字典檔】。
6. 關閉【漢字庫】資料庫。

## 甘字典漢字庫

- 資料庫系統：SQLite
- 漢字資料庫：Kam_Ji_Tian.db
- 漢字庫資料表：漢字庫
- 資料庫用戶端工具：SQLite Studio 3.4.4

### 資料結構 DDL

漢字庫資料的資料結構（Schema）如下：

```sql
CREATE TABLE 漢字庫 (
    識別號  INTEGER PRIMARY KEY AUTOINCREMENT,
    漢字   TEXT    NOT NULL,
    台羅音標 TEXT    NOT NULL,
    常用度  REAL    DEFAULT 0.1,
    摘要說明 TEXT    DEFAULT 'NA',
    時間戳記 TEXT    DEFAULT (DATETIME('now', 'localtime') )
                 NOT NULL
);
```

- 時間戳記：漢字庫每筆資料之時間戳記，及資料時間戳記，能於資料寫入之時留下紀錄。故以如下之【觸發器】，令每筆資料紀錄之建立、更新，均需於【時間戳記】欄自動留下記錄。

### 索引 DDL

由於漢字有【一字多音】之特性，且閩南語之漢字，尚分【文讀音】與【白話音】。為確保【字庫】資料表中之資料能不重複，故以【漢字+台羅音標】之方式建立索引，用此法來成就此目的。

```sql
CREATE UNIQUE INDEX idx_漢字_台羅音標 ON 漢字庫 (
    漢字,
    台羅音標
);
```

### 觸發器 DDL

【漢字庫】資料在建立資料之時，若遇【摘要說明】欄為空值狀況，則需自動代以 "N/A" 字串填入。

```sql
CREATE TRIGGER trg_ensure_default_summary
         AFTER INSERT
            ON 漢字庫
          WHEN NEW.摘要說明 IS NULL
BEGIN
    UPDATE 漢字庫
       SET 摘要說明 = 'N/A'
     WHERE rowid = NEW.rowid;
END;
```
