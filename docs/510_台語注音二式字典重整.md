# 台語注音二式字典重整作業指引 v0.1.1

## 文件摘要

目前的【台語注音二式字典】：`ji_khoo_bpm2.dict.yaml`，因有下列問題，需要重整：

1. 入聲韻尾 `p` / `t` / `k` / `h` 後接錯誤【調號】`1`，應改為陰入調 `4`，如：
    - `jip1` → `jip4`
    - `but1` → `but4`
    - `siok1` → `siok4`
    - `bbeh1` → `bbeh4`

2. 同一字典發生「同漢字、同標音」重複。入聲調號修正後，亦可能使原本不同的兩筆合併為同一鍵，例如：

```yaml
嚇	heh1	0.1	NA	2026-01-02 22:51:07
嚇	heh4	0.01	NA	2025-02-11 11:16:04
```

修正 `heh1` → `heh4` 後，與既有 `heh4` 衝突；匯入時保留先寫入者，略過後續重複。

## 作業流程

依序執行下列程式，完成「台語注音二式字典」重整：

1. **p110**：新建 SQLite 資料庫 `src/台語注音二式字典.db`（僅 Schema）。
2. **p120**：讀取 `ji_khoo_bpm2.dict.yaml`，修正入聲調號後逐筆寫入資料庫；遇重複則略過。
3. **p130**：自資料庫匯出新字典檔 `ji_khoo_bpm2_new.dict.yaml`。

```powershell
py -3 tools/p110_建置字典資料庫.py
py -3 tools/p120_匯入字典.py --replace
py -3 tools/p130_匯出字典.py
```

## 設計規格

### SQLite 資料庫

| 項目 | 說明 |
|------|------|
| 資料庫系統 | SQLite |
| 資料庫檔案 | `src/台語注音二式字典.db` |
| 資料表 | `漢字庫` |
| Schema | `sql/bpm2_ji_tian_schema.sql` |
| 共用模組 | `tools/bpm2_ji_tian_db.py` |

#### 摘要

- 允許漢字【一字多音】（文讀／白話等）。
- 以【漢字】+【漢字標音】為唯一鍵；不可重複。
- 重複寫入時略過，程式不異常終止。

#### 資料結構 DDL

```sql
CREATE TABLE IF NOT EXISTS 漢字庫 (
    識別號  INTEGER PRIMARY KEY AUTOINCREMENT,
    漢字   TEXT    NOT NULL,
    漢字標音 TEXT    NOT NULL,
    常用度  REAL    DEFAULT 0.1,
    摘要說明 TEXT    DEFAULT 'NA',
    時間戳記 TEXT    DEFAULT (DATETIME('now', 'localtime'))
                 NOT NULL
);
```

#### 索引 DDL

```sql
CREATE UNIQUE INDEX IF NOT EXISTS idx_漢字_漢字標音 ON 漢字庫 (
    漢字,
    漢字標音
);
```

#### 觸發器 DDL

【摘要說明】若為 `NULL`，自動填入 `"N/A"`：

```sql
CREATE TRIGGER IF NOT EXISTS trg_ensure_default_summary
         AFTER INSERT
            ON 漢字庫
          WHEN NEW.摘要說明 IS NULL
BEGIN
    UPDATE 漢字庫
       SET 摘要說明 = 'N/A'
     WHERE rowid = NEW.rowid;
END;
```

### 中州韻字典檔

欄位對映：

| 字典欄位 | 資料表欄位 |
|---|---|
| text | 漢字 |
| code | 漢字標音 |
| weight | 常用度 |
| stem | 摘要說明 |
| create | 時間戳記 |

**重整後輸出範例（`ji_khoo_bpm2_new.dict.yaml` 檔頭）：**

```yml
# Rime dictionary
# encoding: utf-8
#
# 台語注音二式字典（重整後）
#
---
name: ji_khoo_bpm2
version: "v0.1.0"
sort: by_weight
use_preset_vocabulary: false
columns:
  - text #漢字／詞彙
  - code #漢字標音（台語注音二式）
  - weight #常用度（優先顯示度）
  - stem #用法舉例
  - create #時間戳記
...
#漢字	漢字標音	常用度	用法舉例	時間戳記
不	but4	0.10	NA	2026-01-02 22:51
嚇	heh4	0.10	NA	2026-01-02 22:51
人	lang5	0.60	【12996】大人, thâi人, phah 人, 人客, 客人.	2026-07-05 21:19
```

說明：

- 輸出為**獨立字典檔**（不含原 `ji_khoo_bpm2.dict.yaml` 的 `import_tables`）。
- 若要以重整結果取代母字典並繼續掛載子字典，需另行併回 `import_tables`。

### p120：匯入字典

| 項目 | 說明 |
|------|------|
| 程式 | `tools/p120_匯入字典.py` |
| 輸入 | `ji_khoo_bpm2.dict.yaml`（可用 `--dict` 指定） |
| 輸出 | `src/台語注音二式字典.db`（可用 `--db` 指定） |

**process：**

1. 略過 YAML 檔頭，自 `...` 之後讀取檔身（tab 分隔）。
2. 遇標音符合正規式 `([ptkh])1$`（入聲韻尾接調號 1）者，改為 `\14`（陰入調 4）。例：`but1` → `but4`；非入聲韻尾如 `ki1` 不變。
3. 將【漢字】、【漢字標音】、【常用度】、【摘要說明】、【時間戳記】寫入 `漢字庫`。
4. 若觸發 `UNIQUE(漢字, 漢字標音)` 衝突：略過該筆，繼續下一筆（先寫入者保留）。
5. 結束時顯示：寫入筆數、略過重複筆數、入聲調號修正筆數。

**常用參數：**

```powershell
py -3 tools/p120_匯入字典.py --replace          # 清空後全量匯入
py -3 tools/p120_匯入字典.py --selftest         # 自我測試
```

### p130：匯出字典

| 項目 | 說明 |
|------|------|
| 程式 | `tools/p130_匯出字典.py` |
| 輸入 | `src/台語注音二式字典.db` |
| 輸出 | `ji_khoo_bpm2_new.dict.yaml`（可用 `--out` 指定） |

**process：**

1. 自 `漢字庫` 依【漢字】、【漢字標音】排序讀取全部紀錄。
2. 寫入中州韻字典檔頭與檔身（欄位對映見上節）。
3. 常用度格式化為兩位小數；時間戳記匯出為 `YYYY-MM-DD HH:MM`。

**常用參數：**

```powershell
py -3 tools/p130_匯出字典.py --selftest
```

## 操作用法

```powershell

# 自我測試
py -3 tools/p120_匯入字典.py --selftest
```
