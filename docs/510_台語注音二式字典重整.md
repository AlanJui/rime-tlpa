# 台語注音二式字典重整作業指引 v0.0.1

## 文件摘要

目前的【台語注音二式字典】：`ji_khoo_bpm2.dict.yaml`，因有下列之問題，需要重調：

1. 入聲韻尾 p/t/k/h 後接錯誤【調號】：1，如：
    - jip1 ==> jip4
    - but1 ==> but4
    - siok1 ==> siok4
    - bbeh1 ==> bbeh4

2. 同一字典，發生「同漢字、同標音」的資料項目重複問題。

```yaml
......
嚇	heh4	0.1	NA	2026-01-02 22:51:07
嚇	heh4	0.01	NA	2025-02-11 11:16:04
```

##  作業流程

執行下列 Python Script ，完成「台語注音二式字典」重整作業：

1. p110.py：新建 SQLite 資料庫：`台語注音二式字典.db`；
2. p120.py：將【中州韻字典檔】：`ji_khoo_bpm2.dict.yaml`，逐筆寫入 SQLite 資料庫；
3. p130.py：將【中州韻字典檔】，轉寫成新中州韻字典檔：`ji_khoo_bpm2_new.dict.yaml`。

## 設計規格

### SQLite 資料庫資料結構

#### 摘要

- 資料結構需求：
  - 可以允許漢字的【一字多音】狀況；
  - 以【漢字】+【漢字標音】當【漢字及標音】索引；
  - 不可以發生【漢字及標音】索引重複狀況。

#### 資料結構 DDL

```sql
CREATE TABLE 漢字典 (
    識別號  INTEGER PRIMARY KEY AUTOINCREMENT,
    漢字   TEXT    NOT NULL,
    漢字標音 TEXT    NOT NULL,
    常用度  REAL    DEFAULT 0.1,
    摘要說明 TEXT    DEFAULT 'NA',
    時間戳記 TEXT    DEFAULT (DATETIME('now', 'localtime') )
                 NOT NULL
);
```

- 時間戳記：漢字庫每筆資料之時間戳記，及資料時間戳記，能於資料寫入之時留下紀錄。故以如下之【觸發器】，令每筆資料紀錄之建立、更新，均需於【時間戳記】欄自動留下記錄。

#### 索引 DDL

由於漢字有【一字多音】之特性，且閩南語之漢字，尚分【文讀音】與【白話音】。為確保【字庫】資料表中之資料能不重複，故以【漢字+漢字標音】之方式建立索引，用此法來成就此目的。

```sql
CREATE UNIQUE INDEX idx_漢字_漢字標音 ON 漢字庫 (
    漢字,
    漢字標音
);
```

#### 觸發器 DDL

【漢字庫】資料在建立資料之時，若遇【摘要說明】欄為空值狀況，則需自動代以 "N/A" 字串填入。

```sql
CREATE TRIGGER trg_ensure_default_summary
         AFTER INSERT
            ON 漢字庫
          WHEN NEW.摘要說明 IS NULL
BEGIN
    UPDATE 漢字庫
       SET 摘要說明 = 'N/A'
     WHERE rowid = NEW.rowid;
END;
```

建置【字典資料庫】。【字典資料庫】為 SQLite 資料庫：`台語注音二式字典.db`。

程式全名：`p110_建置字典資料庫.py`

- input: `None`
- output: `台語注音二式字典.db`；
- process:
    1. 産出【字典資料庫】檔案：`台語注音二式字典.db` 。

### p120.py

將【中州韻字典檔】：`ji_khoo_bpm2.dict.yaml`，逐筆寫入 SQLite 資料庫；

程式全名：`p110_建置字典資料庫.py`

- input: `ji_khoo_bpm2.dict.yaml`
- output: `台語注音二式字典.db`；
- process:
  1. 遇有【台語注音二式】音節之標音為：`([ptkh])1`者，改成`${1}4`
  2. 將【漢字】與【漢字標音】寫入 SQLite 資料庫，若遇【重複】狀況發生時，不要發生【異常終止】，程式能繼續處理字典檔的下一筆。

---

130.py

將【字典資料庫】的資料紀錄，轉寫成新中州韻字典檔：`ji_khoo_bpm2_new.dict.yaml`。

程式全名：`p130_自資料庫匯出成中州韻字典檔.py`

- input: `台語注音二式字典.db`
- output: `ji_khoo_bpm2.dict.yaml`
- process:
  1. 自【字典資料庫】讀取資料紀錄。
  2. 將資料紀錄逐筆寫入【中州韻字典檔】。
