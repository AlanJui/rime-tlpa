# 340 十八音【閩拼方案】需求規格書 v0.2

## 摘要

### 方案識別

- schema_id: tsap_peh_im_bp
- name: 十八音【閩拼方案】
- dictionary: ji_khoo_bpm2
- prism: tsap_peh_im_bp


### 輸入方式（與十八音台羅版相同）

- 順序：聲 + 韻 + 調
- 調鍵（閩拼調號）：`;` 陰平 1、`-` 陽去 6、`_` 陰去 5、`\` 陰上 3、`/` 陽平 2、`[` 陰入 7、`]` 陽入 8。`7`＝促聲通配，`*`＝舒聲通配，`.`＝入聲縮寫，`N`＝鼻化前綴 `n`
- 候選清單：左欄閩拼、右欄十八音。預設【聲調樣式】為調符，如 `bbó [門高五]`。標準調號才是 `bbo2 [門高五]`
- 預設上屏標音：閩拼方案（schema `reset: 6`，初始檔同此）。音節連接符預設撇號
- 字典仍是台語注音二式（`ji_khoo_bpm2`）。拼寫與左欄再編成閩拼；用戶詞典保存的是字典編碼，不是畫面上的調符或上標

## 辭彙解釋

- 【BP】：表【閩拼方案】。
- 【十八音】：表【十五音】之改良版，新增：n【耐】、m【毛】、ng【雅】。

## 需求規格

### 特色

- 套用`十八音【台語注音二式】`（tsap_peh_im_bpm2）修改而得此輸入方案；

- 閩拼方案拼音系統特性：
  - 閩拼遇【零聲母】，且【韻母】首字為【i】或【u】之處理規則；
  - 閩拼之【聲調】編序，與【台羅拼音】不同；
  - 【鼻音韻母】標置方式與【台羅拼音】不同：
    - 【台羅拼音】 ann ==> 【閩拼方案】na；
    - 【台羅拼音】 iann ==> 【閩拼方案】nia；
    - 【台羅拼音】 iaunn ==> 【閩拼方案】niao

### 聲母對映

#### 【聲母對映規則】

台語注音二式與台羅拼音極相似，故以【對映關係】，說明兩者之異同處，條列如下：（參考 phing_im_bpm2）。

|台羅拼音|注音二式|閩拼方案|例子|
|--------|--------|--------|----|
| b / p / ph   | bb / b / p    | bb / b / p     | 門 bb、邊 b、頗 p   |
| g / k / kh   | gg / g / k    | gg / g / k     | 語 gg、求 g、氣 k   |
| j / ts / tsh | zz / z / c    | zz / z / c     | 入 zz、曾 z、出 c   |
| m / n / ng   | m / n / ng    | bbn / ln / ggn | 毛 bbn、耐 ln、雅 ggn |

**`【驗證查核重點】`**：

預設【聲調樣式】為調符。下表「音節」是閩拼標準調號；左欄在調符時不顯示數字。`&`、`*` 仍同時查出對應的本調。

| 音節 | 按鍵 | 輸入框 | 候選清單（調符） |
|------|------|--------|------------------|
| 無 bbo2  | `bbo/`        | `bbó` | 無 `bbó [門高五]` |
| 床 cong2 | `cong/`       | `cóng` | 床 `cóng [出公五]` |
| 不 but7  | `but[` / `bun[` | `būt` | 不 `būt [邊君四]` |
| 好 ho3   | `ho\`         | `hǒ` | 好 `hǒ [喜高二]` |
| 不 but7  | `but&`        |  | 同時出陰入、陽入 |
| 無 bbo2  | `bbo*`        |  | 同時出可對到的舒聲 |

#### 【聲母顎化處理】

在【**閩拼方案**】此種**自動更正**處理不需要。

【台語注音二式】的【聲母】：`j` [ʣ] ，在【閩拼】改以【zz】表示。

在【閩拼方案】，聲母： zz, z, c, s ，其後接【韻母】，且韻母之首字為 i ，聲母無需有所改變。

但【台語拼音二式】聲母： zz, z, c, s ，其後接【韻母】，且韻母之首字為 i ，前面聲母需改為：jji, ji, chi, shi。

當使用者輸入有錯，【台語注音二式】輸入方案之處理作業，將自動更正：

|誤打|自動更正|實測|
|----|--------|----|
|zi  | ji     |zi\ → 編輯列 ji²，出「只」等|
|ci  | chi    |cit[ → chit⁴，出「七」|
|si  | shi    |si- → shi⁷|
|zzi | jji    |zzi\ → jji²（子）；zzit] → jjit⁸（日）|

#### 【台語注音二式字典使用注意事項】

採用【台語注音二式】編碼用【字典】，轉換成【閩拼方案】時，需留心下列事項，以免發生轉換錯誤，如：【生】字之【台語注音二式】：【shinn1】轉成【閩拼】應為：【sni1】，不要轉為：【shni1】。

1. 【台語注音二式】的【聲母】：`j` [ʣ] ，在【閩拼】以【zz】標示。

2. 在【閩拼方案】，聲母： zz, z, c, s ，其後接【韻母】，且韻母之首字為 i ，聲母無需有所改變。

3. 但【台語注音二式】聲母： zz, z, c, s ，其後接【韻母】，且韻母之首字為 i ，前面聲母需改為：jji, ji, chi, shi。

4. 【台語注音二式】聲母： zz, z, c, s ，其後若接【鼻音韻母】： inn ，則前面聲母配合變更成：jjinn, jinn, chinn, shinn。

5.【台語注音二式】以 `nn` 作為【鼻音韻母識別符號】。【鼻音韻母】採【後綴】方式來標示，如：ann, iann, iaunn。

6.【閩拼方案】則以 `n` 作為【鼻音韻母識別符號】。【鼻音韻母】採【前綴】方式來標示，如：na, nia, niao （iao = iau）。

7. 【台語注音二式】標音轉【閩拼】時，處理： `jjinn, jinn, chinn, shinn` 之轉換，需嚴循以下順序：
    7.1 jjinn, jinn, chinn, shinn ==> zzinn, zinn, cinn, sinn
    7.2 zzinn, zinn, cinn, sinn ==> zzni, zni, cni, sni

#### 【特殊聲母處理】

【台語注音二式】與【閩拼方案】有下表之對映關係：

|注音二式|閩拼方案|十五音聲母|
|--------|--------|:--------:|
| m      | bbn    | 毛       |
| n      | ln     | 耐       |
| ng     | ggn    | 雅       |

為方便使用者，提供【聲母相容特殊處理】，可用： `m/n/ng` ，代 `bbn/ln/ggn` 。

1. 【輸入框】可接受相容聲母：ng=ggn、m=bbn、n=ln；
2. 【候選清單】只採用【閩拼標音】標準寫法:ggn、bbn、ln。

此種處理作業需留心以下細節：

1. m/n/ng 既可為【聲母】，亦可為【韻母】的【韻尾】；
2. m/ng 亦屬【韻化輔音】，可當【韻母】使用；
3. n 亦可當成【**鼻音韻母識別符號**】。

**`設計規格`**

現在字典裡的聲母 m、n、ng 在組字時已換成 bbn、ln、ggn，所以要打出「毛、耐、雅」得按 bbn、ln、ggn。preedit_format 只改輸入框的顯示，不改實際對到哪一條音。若希望按鍵仍是 m、ng，卻在輸入框看到 bbn、ggn，顯示規則與拼寫都要一起做：拼寫用衍生保留兩種按法，輸入框再把聲母位置的字母換成閩拼。

改成 derive，只讓拼寫多收一組按鍵；候選左欄、Enter、Shift+Ctrl+Enter 仍走 comment_format 裡的 xform，左欄繼續是 bbn、ln、ggn。

在 `speller/algebra` 節中，不用 `xform` ，改用 `derive` ，以便 ng=ggn, n=ln, m=bbn 的**等同**關係能保持。

【輸入框】顯示的是實際【按鍵】。如，欲輸入漢字【**年**】，【按鍵】輸入： **`ni/`** 時，【輸入框】顯示： **`ní`**，但【候選清單】中【漢字標音】左欄顯示 **`lní`**。

要留意的是聲母 n 和鼻化前綴撞鍵。鼻化韻在後面才改成 n 起頭，而 derive 又把注音二式的 n 留下，兩組字會共用同一串按鍵：

| 按鍵 | 鼻化韻 | 聲母【耐】 |
|---|---|---|
| `na` / `Na` | 監（ann） | 耐 + a |
| `nai` / `Nai` | 閒（ainn） | 耐 + ai |
| `ne` / `Ne` | 更（enn） | 耐 + e |
| `nao` / `Nao` | 爻（aunn） | 耐 + au |
| `noo` / `Noo` | 姑（oonn） | 耐 + oo |

```yaml
speller:
  algebra:
    ......
    #--------------------------------------------------------------------------
    # 聲母相容特殊處理：ng→ggn、m→bbn、n→ln
    # 1. 【輸入框】可接受相容聲母：ng=ggn、m=bbn、n=ln；
    # 2. 【候選清單】只採用【閩拼標音】標準寫法:ggn、bbn、ln。
    #--------------------------------------------------------------------------
    - 'derive/(^| )ng(?![0-9h])/$1ggn/'
    - 'derive/(^| )m(?![0-9h])/$1bbn/'
    - 'derive/(^| )n(?![g0-9h])/$1ln/'
```

### 韻母對映

#### 【韻母對映規則】

|台羅拼音|注音二式|閩拼方案|例子|
|--------|--------|--------|----|
| oo     | oo     | oo     | 沽 (舒) |
| o      | or     | o      | 高 (舒) ，好 ho3|
| io     | ior    | io     | 茄 (舒) |
| ioh    | iorh   | ioh    | 茄 (促) |
| ik     | iek    | ik     | 經 (促) ，益 ik7|
| iok    | iook   | iok    | 恭 (促) |

提供【台羅】相容功能，如： `au`，【按鍵】輸入 `au` 等同 `ao`，輸入方案的 `preedit_format` 處理作業，會將 `au` 改成 `ao` ，並於【輸入框】顯示更正後的結果： `ao`。輸入 `iau` 時，亦會自動更正成 `iao`。

此種等同的相容處理，尚可避免使用者輸入： `lau` 時，會被中州韻的自動分割功能，切成： `la` + `零聲母u`，致使預期輸出的【老】字 變成 → 【啦有】。

零聲母 `iu`（友）寫成 `yiu`，不是 `yu`。`i` 留在韻母裡，前面加 `y`。`yu` 仍可打，輸入框改顯示 `yiu`。若只收 `yu`，連打 `bing-yiu` 會被切成 `yi` + `u`（衣＋有）。

#### 【鼻音韻母處理】

##### `【標音對映規則】`

【台語注音二式】以 `nn` 作為【**鼻音韻母識別符號**】。【**鼻音韻母**】採【後綴】方式來標示，如：ann, iann, iaunn。

【閩拼方案】則以 `n` 作為【**鼻音韻母識別符號**】。【**鼻音韻母**】採【前綴】方式來標示，如：na, nia, niao （iao = iau）。

| 台語注音二式 | 閩拼方案 |
|--------------|----------|
| ann      | na       |
| iann     | nia      |
| iaunn    | niao     |
| uainn    | nuai     |

##### `【輸入框處理規則】`

【輸入框】顯示【**鼻音韻母識別符號**】可不用 `n` ，改用 `ⁿ` 代。因此作法，有助於視覺之快速辨視。

##### `【候選清單處理規則】`

【候選清單】顯示漢字拼音字母時，【**鼻音韻母識別符號**】仍使用 `n` 。

    - 鼻韻母：na, ni, ne, no, nai, nia, niu, nio, nua, nuai, niao
    - na=ⁿa
    - ni=ⁿi
    - ne=ⁿe
    - no=ⁿo
    - nai=ⁿai
    - … 請類推

1. 遇 ?nn 用 ⁿ? 代。【ⁿ】為【鼻韵母符號】。
    【鍵入】：【nn】，【輸入框】：顯示【ⁿ】代。【候選清單】則不變。

    《例》： 漢字【腔】，BPM2【kiunn1】==》BP【kniu1】。
        - 【按鍵】輸入： `k + (n + i + u) + ;`
        - 【輸入框】顯示：【kⁿiu】代
        - 【候選清單】顯示：【kniū】。

2. 支援鼻韻母符號輸入按鍵【N】。

鍵入【N】，等同輸入【**鼻音韻母識別符號**】： `ⁿ` 。故【按鍵】輸入：`Na`，則【輸入框】顯示：【ⁿa】。但【**候選清單**】中顯示之拼音字母，無需跟著【候選清單】變更。

## 設計規格

### 上屏鍵

- Space: 【漢字】上屏
- Enter: 【漢字標音】上屏
- Ctrl+Enter: 【按鍵】上屏
- Shift+Enter: 【輸入框】上屏
- Shift+Ctrl+Enter: 【漢字】與【漢字標音】上屏
- G/H/J/K/L: 候選清單本頁第 1～5 項，上屏【漢字】
- Shift+Ctrl+G/H/J/K/L: 候選清單當頁第 1～5 項，上屏【漢字】與【漢字標音】（與 Shift+Ctrl+Enter 同一格式，含【聲調樣式】）

```yaml
editor:
  bindings:
    Return: commit_composition
    Control+Return: commit_raw_input
    Shift+Return: commit_script_text
    # Control+Shift+Return 由 lua_processor@aux_commit 攔截
```

#### 漢字帶標音上屏鍵

使用【拼音字母】之輸入方案（如：台羅拼音、台語音標、白話字、台語注音二式、閩拼方案），當【候選清單】顯示 **`5項`** 與【輸入框】相符之【漢字】及【漢字標音】時，使用者可用【大寫英文字母】： `G/H/J/K/L` 直接選用。候選清單被選用之項目，會將【漢字】上屏。

若使用者欲上屏之標的為：漢字與漢字標音，則可使用**組合按鍵**：【 `Shift` + `Ctrl` + `G/H/J/K/L` 】，達成上述需求。將原本的 `Shift+Ctrl+Enter` 漢字帶標音上屏功能，予以再升級。

**`【使用限制】`**

在 Windows 11 作業系統之【筆記本】App，可正常操作；但在【Word】之中，因 Word 預設之【快捷鍵】多有用到，可能會失效：

| 按鍵 | Word 預設動作 |
|---|---|
| `Shift+Ctrl+H` | 隱藏文字 |
| `Shift+Ctrl+K` | 小型大寫 |
| `Shift+Ctrl+L` | 項目符號 |
| `Shift+Ctrl+Enter` | 分欄符號 |
| `Shift+Ctrl+G`、`Shift+Ctrl+J` | 常用表未列；仍請在「請按新的快速鍵」按一次，看「目前指定至」 |

若有衝突問題發生，可考慮依下敘之操作步驟，將與 Word 相衝突之預設快捷鍵關閉：

1. 開啟【檔案】 → 【選項】 → 【自訂功能區】。
2. 左下方【鍵盤快速鍵】旁按【自訂】。
3. 【將自訂儲存於】下拉式選項，設定在 `Normal` ，即：變更結果存放在 Normal.dotm 模版檔，往後每個新文件都會沿用。
4. 滑鼠指標點擊【按新設定的快速鍵】輸入方塊，待游標顯現後，先按下【快捷鍵】（如：Shift+Ctrl+H）。
5. 再查看【現用代表鍵】方塊下之【目前指定於】，該處所顯示之**命令名稱**（如：Hidden），說明該組快捷鍵目前為那個 Word 功能所使用。
6. 在【類別】選【所有命令】，然後再到右邊的【命令】裡點擊該**命令名稱**（如：Hidden）。
7. 在【現用代表鍵】先選擇那組快捷鍵，再按底端的【移除】按鈕。
8. 其餘組合重複 4～7，最後按 關閉。Word 若問是否儲存 Normal.dotm，選【是】。

#### 用戶詞典（User Dictionary）

常人所謂之【常用字集】，在 Rime 應正名為：**用戶詞典**，其**功用**為：【候選清單】中的【漢字】、【漢字標音】於上屏後，會將選用的【漢字】和【讀音碼】（即：字典的音節編碼，簡稱：字典編碼）留下保存紀錄；下回再遇【輸入框】有同樣之【字典編碼】輸入時，便會在【候選清單】優先顯示。

**`【參考資料】`**

| 常人講法 | Rime／小狼毫標準名稱 | 內容 |
|----------|----------------------|------|
| 常用字集 | 用戶詞典（user dictionary） | 用過的漢字，加上字典讀音碼、權重 |
| 中州韻字典檔 | 用戶詞典檔名            | 例如 `ji_khoo_tl`、`ji_khoo_bpm2` |
| 詞典快照 | 用戶詞典的備份              | 整份搬到另一台，或事後合回來 |
| 文本碼表 | 用戶詞典匯出的文字表        | 漢字、讀音碼、權重，可改完再匯入 |

**`【十八音系列輸入方案使用之用戶詞典】`**

十八音系列之輸入方案條列如下：

- 十八音【方音符號】（tsap_peh_im_tps）
- 十八音【台羅拼音】（tsap_peh_im_tl）
- 十八音【台語注音二式】（tsap_peh_im_bpm2）
- 十八音【閩拼方案】（tsap_peh_im_bp）

| 輸入方案 | 用戶詞典 |
|----------|----------|
| 十八音【台羅拼音】、【方音符號】 | `ji_khoo_tl` |
| 十八音【閩拼方案】、【台語注音二式】 | `ji_khoo_bpm2` |

寫進【用戶詞典】的【讀音碼】為輸入方案使用之【字典檔】的【漢字標音】編碼。本方案使用之【字典檔】為【台語注音二式】字典檔，該字典檔使用之【漢字標音】，採：`聲母+韻母+音調` 格式，【**音調**】之標示，採**數值**格式（如 `shinn1`）。

所以，保存在【用戶詞典】檔的【讀音碼】會是：**`shinn1`**；而不是： **`snī`**，或是 **`sni¹`**。`custom_code` 末尾保留一格空白，Rime 才認這筆。

### 聲調樣式

【輸入方案選項】：【聲調樣式】功能，使用者可更換【聲調】呈現之樣式：

1. 調符；
2. 上標調號；
3. 標準調號。

| 輸入方案 | 聲調樣式預設 | 輸入框（固定） | 調符 | 上標調號 | 標準調號 |
|----------|--------------|----------------|------|----------|----------|
| 台羅拼音 |調符（台羅拼音）| 調符，如 `bí` | `bí` | `bi²` | `bi2` |
| 台語注音二式 |標準調號    | 標準調號，如 `bbi2` | `bbi2` | `bbi²` | `bbi2` |
| 閩拼方案 |調符（閩拼方案）| 調符，如 `lní` | `lní` | `lni²` | `lni2` |
| 方音符號 |調符（方音符號）| 調符，如 `ㆠㄧˋ` | `ㆠㄧˋ` | `ㆠㄧ²` | `ㆠㄧ2` |

輸入方案選項：【聲調樣式】之變更，不影響【輸入框】之【聲調】呈現樣式（preedit）。即：輸入方案在【輸入框】呈現的【聲調】樣式，若原本為【調符】；即便**輸入方案選項**之【**聲調樣式**】變更成【上標調號】，在【輸入框】所見之【聲調樣式】，不會跟著變成【**上標調號**】；應仍維持使用【**調符**】。

【**聲調樣式**】選項之變更，影響所及止於：

1. 【候選清單】漢字標音左欄；
2. 上屏鍵（且當時【漢字標音選項】正是該方案自己的標音）：
   - Enter
   - Shift+Ctrl+Enter
   - Shift+Ctrl+G/H/J/K/L

Space、G/H/J/K/L 只上屏漢字，不帶標音，故不受【聲調樣式】影響。Ctrl+Enter 上屏按鍵、Shift+Enter 上屏輸入框原文，也不走這個選項。

【標變調】開啟時，上述三組上屏鍵改走【變調標示】，【聲調樣式】對它們失效。候選左欄仍跟【聲調樣式】。

### 變調標音上屏

【變調標示】（`piau_piann_tiau`）的 states 為【無變調】、【標變調】。預設【無變調】。`get_option("piau_piann_tiau")` 只在【標變調】時為 true。十八音四個方案都有這個選項；本節記閩拼方案。

【標變調】優先於【漢字標音選項】與【聲調樣式】。設成【標變調】後，下列上屏鍵一律輸出閩拼、聲調一律上標。漢字標音改成台羅或其他系統、聲調樣式改成調符或標準調號，都不改變這三組鍵：

1. Enter：只上屏標音
2. Shift+Ctrl+Enter：漢字〔標音〕
3. Shift+Ctrl+G/H/J/K/L：當頁第 1～5 項，格式同 Shift+Ctrl+Enter

| 音節數 | 上屏 |
|---|---|
| 一個 | 閩拼上標本調。多〔do¹〕。不標變調 |
| 兩個以上 | 非末字寫本調⁻變調，末字只留本調。音節以空白分開，不用撇號。多謝〔do¹⁻⁶ sia⁶〕、閩南話〔bban²⁻⁶ lam²⁻⁶ we⁶〕 |

其他例子：先生 `sian¹⁻⁶ sni¹`；做甚物〔zue⁵⁻³ sim⁶⁻⁵ bbnih⁸〕。

變調鏈（閩拼調號）：

| 韻尾 | 本調 → 變調 |
|---|---|
| 舒聲 | 1→6、6→5、5→3、3→1；陽平 2→6 |
| -p／-t／-k | 7↔8 |
| -h | 陰入 7→3；陽入 8→5 |

查字時，-h 陽入另收一層 8→7（陰入），所以上屏未標的那組變調仍打得到。上屏只標 ⁸⁻⁵。

【標變調】不改這些地方：

- 輸入框仍是閩拼調符
- 候選左欄仍是本調，並跟著【聲調樣式】
- Space、G/H/J/K/L 仍只上屏漢字
- 用戶詞典仍存 `ji_khoo_bpm2` 的字典編碼（如 `shinn1`），不存 `sni¹⁻⁶` 這種上屏字串

【無變調】時，上屏回到漢字標音與聲調樣式；連打音節沿用【音節連接符】（本方案預設撇號），例如黃〔ńg〕腔〔kniū〕在撇號下為 `ńg'kniū`。

拼寫用的變調（`speller/algebra` 的 derive）是另一件事：連打時改打變調鍵，仍查得到本調字。那組規則寫在字典的注音二式調號上（1→7、7→3、3→2、2→1、5→7，入聲另計），對到閩拼鍵之後與上表同一條鏈。衍生只做一層，避免 1 一路通到整圈。候選排序仍讓本調排在變調前面。

#### 記錄方案選項的【狀態檔】

1. 輸入方案之【方案選項】狀態，保存於 rime_env_state.lua 設定檔案中。每當輸入方案被【啟用】時，輸入方案欲對【方案選項】進行設定時，則自檔案：**`rime_env_state.lua`** 讀取前次的設定狀態，用以重設輸入方案的各【方案選項】。

>【**註**】：librime 會在輸入方案的 Lua 元件（插件）初始化之後，依 schema 的 reset 把開關設回預設。還原是接在這批預設值套完的那一刻，所以打開 F4 選單時，看到的已是上次的選擇。
