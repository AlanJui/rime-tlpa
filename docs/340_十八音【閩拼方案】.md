# 340 十八音【閩拼方案】需求規格書

## 摘要

### 方案識別

- schema_id: tsap_peh_im_bp
- name: 十八音【閩拼方案】
- dictionary: ji_khoo_bpm2
- prism: tsap_peh_im_bp


### 輸入方式（與十八音台羅版相同）

- 順序：聲 + 韻 + 調
- 調號：; - _ \ / [ ]，7＝促聲通配，*＝舒聲通配
- 候選註解：bbor5 [門高五]（每個漢字配兩欄【漢字標音】；左欄：台語注音二式，右欄：十八音）
- 預設上屏標音：台語注音二式

## 辭彙解釋

- 【BP】：表【閩拼方案】。
- 【十八音】：表【十五音】之改良版，新增：n【耐】、m【毛】、ng【雅】。

## 需求規格

### 特色

- 套用`十八音【閩拼方案】`（tsap_peh_im_bpm2）修改而得此輸入方案；

- 閩拼方案拼音系統特性：
  - 閩拼遇【零聲母】，且【韻母】首字為【i】或【u】之處理規則；
  - 閩拼之【聲調】編序，與【台羅拼音】不同；
  - 【鼻音韻母】標置方式與【台羅拼音】不同：
    - 【台羅拼音】 ann ==> 【閩拼方案】na；
    - 【台羅拼音】 iann ==> 【閩拼方案】nia；
    - 【台羅拼音】 iaunn ==> 【閩拼方案】niao

### 顎化相容

在【**閩拼方案**】此種**自動更正**處理不需要。

在【台羅拼音】，聲母： z, c, s, j ，其後接【韻母】，若韻母之首字為 i ，前面聲母仍不變。

但【台語拼音二式】聲母： z, c, s, zz ，其後接【韻母】，若韻母之首字為 i ，前面聲母需改為：j, ch, sh, jj。

當使用者輸入有錯，【台語注音二式】輸入方案之處理作業，將自動更正：

|誤打|自動更正|實測|
|----|--------|----|
|zi |ji |zi\ → 編輯列 ji²，出「只」等|
|ci |chi |cit[ → chit⁴，出「七」|
|si |shi |si- → shi⁷|
|zzi |jji |zzi\ → jji²（子）；zzit] → jjit⁸（日）|

### 鼻韻母處理

#### 拼音系統處理規則

閩拼方案對於【鼻音韻母】，以`n`作為【**鼻音韻母識別符號**】。

| 台羅拼音 | 閩拼方案 |
|----------|----------|
| ann | na |
| iann | nia |
| uainn | nuai |
| iaunn | niao |

#### 輸入框處理規則

【輸入框】顯示【**鼻音韻母識別符號**】可不用 `n` ，改用 `ⁿ` 代。因此作法，有助於視覺之快速辨視。

#### 候選清單處理規則

【候選清單】顯示漢字拼音字母時，【**鼻音韻母識別符號**】仍使用 `n` 。

    - 鼻韻母：na, ni, ne, no, nai, nia, niu, nio, nua, nuai, niao。
    - na=ⁿa
    - ni=ⁿi
    - ne=ⁿe
    - no=ⁿo
    - nai=ⁿai
    - … 請類推

1. 遇 ?nn 用 ⁿ? 代。【ⁿ】為【鼻韵母符號】。
    【鍵入】：【nn】，【輸入框】：顯示【ⁿ】代。【候選清單】則不變。

    《例》： 漢字【腔】，BPM2【kiunn1】==》BP【kniu1】。
        - 【按鍵】輸入： `k + (n + i + u) + ;`
        - 【輸入框】顯示：【kⁿiu】代
        - 【候選清單】顯示：【kniū】。

2. 支援鼻韻母符號輸入按鍵【N】。

鍵入【N】，等同輸入【**鼻音韻母識別符號**】： `ⁿ` 。故【按鍵】輸入：`Na`，則【輸入框】顯示：【ⁿa】。但【**候選清單**】中顯示之拼音字母，無需跟著【候選清單】變更。
