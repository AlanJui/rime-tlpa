# 中州韻字典重整作業指引 v0.2.1

## 文件摘要

多種【中州韻字典檔】（台語注音二式、台羅拼音等）可能有下列問題，需重整：

1. 入聲韻尾 `p` / `t` / `k` / `h` 後接錯誤【調號】`1`，應改為陰入調 `4`，如：
    - `jip1` → `jip4`
    - `but1` → `but4`
    - `siok1` → `siok4`
    - `bbeh1` → `bbeh4`

2. 修正同一字典，發生「同漢字、同標音」重複之問題：

   - 在中州韻字典檔(xxx.dict.yaml)建檔之時，不小心重複輸入 2 次以上；
   - 入聲調號修正後，亦可能使原本不同的兩筆合併為同一鍵，例如：

```yaml
嚇	heh1	0.1	NA	2026-01-02 22:51:07
嚇	heh4	0.01	NA	2025-02-11 11:16:04
```

修正 `heh1` → `heh4` 後，與既有 `heh4` 衝突；匯入時保留先寫入者，略過後續重複。

同一套 `p110`／`p120`／`p130` 透過 `--profile` 選擇目標字典與資料庫。

## 字典設定（profile）

定義於 `tools/ji_tian_profiles.py`。內建：

| profile | 拼音系統 | 來源字典 | 資料庫 | 輸出字典 |
|---|---|---|---|---|
| `bpm2`（預設） | 台語注音二式 | `ji_khoo_bpm2.dict.yaml` | `src/台語注音二式字典.db` | `ji_khoo_bpm2_new.dict.yaml` |
| `tl` | 台羅拼音 | `ji_khoo_tl_HanJi.dict.yaml` | `src/台羅拼音字典.db` | `ji_khoo_tl_HanJi_new.dict.yaml` |

亦可在命令列以 `--dict`／`--db`／`--out` 覆寫個別路徑，處理未登錄之字典檔。

擴充新字典：於 `PROFILES` 新增一筆 `DictProfile` 即可。

## 作業流程

依序執行（以 `--profile` 指定目標）：

1. **p110**：新建該 profile 之 SQLite 資料庫（僅 Schema）。
2. **p120**：讀取來源字典，修正入聲調號後寫入資料庫；遇重複則略過。
3. **p130**：自資料庫匯出重整後字典。

```powershell
# 台語注音二式
py -3 tools/p110_建置字典資料庫.py --profile bpm2
py -3 tools/p120_匯入字典.py --profile bpm2 --replace
py -3 tools/p130_匯出字典.py --profile bpm2

# 台羅拼音（ji_khoo_tl_HanJi → 台羅拼音字典.db）
py -3 tools/p110_建置字典資料庫.py --profile tl
py -3 tools/p120_匯入字典.py --profile tl --replace
py -3 tools/p130_匯出字典.py --profile tl
```

## 設計規格

### SQLite 資料庫

| 項目 | 說明 |
|------|------|
| 資料庫系統 | SQLite |
| 資料表 | `漢字庫`（各 profile 各用一個 `.db` 檔） |
| Schema | `sql/ji_tian_schema.sql` |
| 共用模組 | `tools/ji_tian_db.py`、`tools/ji_tian_profiles.py` |

#### 摘要

- 允許漢字【一字多音】（文讀／白話等）。
- 以【漢字】+【漢字標音】為唯一鍵；不可重複。
- 重複寫入時略過，程式不異常終止。

#### 資料結構 DDL

```sql
CREATE TABLE IF NOT EXISTS 漢字庫 (
    識別號  INTEGER PRIMARY KEY AUTOINCREMENT,
    漢字   TEXT    NOT NULL,
    漢字標音 TEXT    NOT NULL,
    常用度  REAL    DEFAULT 0.1,
    摘要說明 TEXT    DEFAULT 'NA',
    時間戳記 TEXT    DEFAULT (DATETIME('now', 'localtime'))
                 NOT NULL
);
```

#### 索引 DDL

```sql
CREATE UNIQUE INDEX IF NOT EXISTS idx_漢字_漢字標音 ON 漢字庫 (
    漢字,
    漢字標音
);
```

#### 觸發器 DDL

【摘要說明】若為 `NULL`，自動填入 `"N/A"`：

```sql
CREATE TRIGGER IF NOT EXISTS trg_ensure_default_summary
         AFTER INSERT
            ON 漢字庫
          WHEN NEW.摘要說明 IS NULL
BEGIN
    UPDATE 漢字庫
       SET 摘要說明 = 'N/A'
     WHERE rowid = NEW.rowid;
END;
```

### 中州韻字典檔

欄位對映：

| 字典欄位 | 資料表欄位 |
|---|---|
| text | 漢字 |
| code | 漢字標音 |
| weight | 常用度 |
| stem | 摘要說明 |
| create | 時間戳記 |

輸出為**獨立字典檔**（不含原檔之 `import_tables`）。若要取代母字典並繼續掛載子字典，需另行併回 `import_tables`。

檔頭之 `name`、標題註解、code 欄註解依 profile 設定。

### p110：建置字典資料庫

| 項目 | 說明 |
|------|------|
| 程式 | `tools/p110_建置字典資料庫.py` |
| 輸入 | `--profile`（讀取 `sql/ji_tian_schema.sql`） |
| 輸出 | 該 profile 之 `.db`（可用 `--db` 覆寫） |

**process：**

1. 依 Schema 建立／更新資料表 `漢字庫`、唯一索引、觸發器。
2. 顯示 profile、資料庫路徑、索引與觸發器名稱。

---

### p120：匯入字典

| 項目 | 說明 |
|------|------|
| 程式 | `tools/p120_匯入字典.py` |
| 輸入 | profile 來源字典（可用 `--dict` 覆寫） |
| 輸出 | profile 資料庫（可用 `--db` 覆寫） |

**process：**

1. 略過 YAML 檔頭，自 `...` 之後讀取檔身（tab 分隔）。
2. 遇標音符合 `([ptkh])1$` 者，改為 `\14`（陰入調 4）。例：`but1` → `but4`；非入聲韻尾如 `ki1` 不變。BPM2／台羅皆適用。
3. 寫入 `漢字庫`；UNIQUE 衝突則略過（先寫入者保留）。
4. 結束時顯示：寫入／略過重複／入聲調號修正筆數。

---

### p130：匯出字典

| 項目 | 說明 |
|------|------|
| 程式 | `tools/p130_匯出字典.py` |
| 輸入 | profile 資料庫（可用 `--db` 覆寫） |
| 輸出 | profile 輸出字典（可用 `--out` 覆寫） |

**process：**

1. 自 `漢字庫` 依【漢字】、【漢字標音】排序讀取。
2. 依 profile 寫入檔頭與檔身。
3. 常用度兩位小數；時間戳記 `YYYY-MM-DD HH:MM`。

## 檔案清單與預設路徑

| 檔案 | 用途 |
|------|------|
| `sql/ji_tian_schema.sql` | 資料表／唯一索引／觸發器 |
| `tools/ji_tian_db.py` | SQLite 共用模組 |

（`sql/bpm2_ji_tian_schema.sql`、`tools/bpm2_ji_tian_db.py` 為舊路徑相容轉接。）

## 操作用法

```powershell
# --- 台語注音二式（profile=bpm2，可省略 --profile）---
py -3 tools/p110_建置字典資料庫.py --profile bpm2
py -3 tools/p120_匯入字典.py --profile bpm2 --replace
py -3 tools/p130_匯出字典.py --profile bpm2

# --- 台羅拼音 ---
py -3 tools/p110_建置字典資料庫.py --profile tl
py -3 tools/p120_匯入字典.py --profile tl --replace
py -3 tools/p130_匯出字典.py --profile tl

# 任意字典（覆寫路徑）
py -3 tools/p120_匯入字典.py --dict ji_khoo_tl.dict.yaml --db src/台羅拼音字典.db --replace
py -3 tools/p130_匯出字典.py --profile tl --out ji_khoo_tl_new.dict.yaml

# 自我測試
py -3 tools/p120_匯入字典.py --selftest
py -3 tools/p130_匯出字典.py --selftest
```
