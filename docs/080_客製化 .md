# 中州韻輸入方案客製

中州韻之【輸入方案】，使用者可透過【使用者客製設定檔】，變更輸入方案之【選項】的【預設值】。

## 使用者客製設定檔

假設輸入方案之檔名為：【**huan_ciat_tps**.schema.yaml】，則使用者客製設定檔之檔名為：【huan_ciat_tps.**`custom`**.yaml】 。

### 輸入方案

```yml
# Rime schema
# vim: set sw=2 sts=2 et nowrap:
# encoding: utf-8

schema:
  schema_id: huan_ciat_tps
  name: 反切輸入法【方音符號】
  version: "v0.1.0"
  author:
    - 居正中 <alanjui.1960@gmail.com>
  description: |
    使用者輸入【方音符號】按鍵，輸入法會將【方音符號】轉換成【十五音】的【聲母】、【韻母】
    與【聲調】；同時輸入法亦會根據使用者已輸入的【方音符號】，推測可能的【漢字】及其【讀音】，
    並顯示於【候選字清單】中，供使用者選擇。漢字的【讀音】以兩種方式呈現：一為【十五音反切】；
    另一為【方音符號】。

    【拼音系統】：台語音標+（TLPA+）
    【字典編碼】：【台羅拼音】
    【輸入類型】：注音輸入法
    【注音符號】：極簡化方音符號，適合懶地背記按鍵位置的使用者。
    【特性簡介】：
      1. 使用者輸入的【方音符號】按鍵，會轉換成【十五音】的【聲母】、【韻母】與【聲調】；
         如使用者輸入：ㄒㄧㄣˊ，輸入法的【輸入列】會顯示：【時巾五】
      2. 【侯選清單】：以【十五音反切】、【方音符號】兩欄標示，如：〔巾五時〕【ㄒㄧㄣˊ】
      3. 【聲調標示】：
          (a) 採【台羅八聲調】為【調名】；
          (b) 調號採與【注音符號】相容的【方音符號】。

switches:
  - name: ascii_mode
    reset: 0
    states: [漢文, ABC]
  - name: full_shape
    reset: 0
    states: [半形, 全形]
  # 【漢字標音選項】控制輸出按鍵 [Enter] 與 [Ctrl+Shift+Enter] 在上屏時，
  # 【漢字標音】應以何種【注音/拼音系統】標示漢字之讀音。
  # 【註】options 與 states 依「位置序號」一一對應，兩列表之項目數與排序必須一致，
  #       否則選單顯示之名稱與實際啟動之選項會錯位。
  - options:
      [ key_in_piau_im_sni, key_in_piau_im_tps, key_in_piau_im_tlpa,
        key_in_piau_im_tlpa_zu_im, key_in_piau_im_tl, key_in_piau_im_poj,
        key_in_piau_im_bp, key_in_piau_im_bpm2, key_in_piau_im_ipa ]
    reset: 0
    states: [ 十五音, 方音符號, 台語音標, 台語音標注音, 台羅拼音, 白話字, 閩拼方案, 台語注音二式, 國際音標 ]

engine:
  processors:
    - lua_processor@aux_commit    # 輸出【漢字標音】，而非【漢字】
    - lua_processor@jump_select   # 務必置頂，用以攔截【快捷鍵】，如：Ctrl+M, Ctrl+<, Ctrl+>
    - ascii_composer
    - recognizer
    - key_binder
    - speller
    - punctuator
    - selector
    - navigator
    - fluid_editor
    # - express_editor
  segmentors:
    - ascii_segmentor
    - matcher
    - abc_segmentor
    - punct_segmentor
    - fallback_segmentor
  translators:
    - punct_translator
    - script_translator
  filters:
    - simplifier
    - uniquifier
    # 為 filter 除錯用
    # - lua_filter@append_ok_filter
    # - lua_filter@force_mark_filter
    - lua_filter@reformat_comment_filter

speller:
  alphabet: "!1qas2wxEedNYyhncRrfv8uKj,ikmp/btgz9lM0;Oo*UJ<I(L-=\"5346][7"
  initials: "!1qas2wxEedNYyhncRrfv8uKj,ikmp/btgz9lM0;Oo*UJ<I(L-="
  finals: "\"5346][7."
  delimiter: "'"
  use_space: true
  #=============================================================================
  # 定義【注音符號】編碼及【鍵盤按鍵】對映之【注音編碼】
  #=============================================================================
  algebra:
  ......
```

### 使用者客製設定檔

```yml
switches/options: [key_in_piau_im_tl, key_in_piau_im_sni, key_in_piau_im_tps, key_in_piau_im_tlpa_zu_im,
        key_in_piau_im_tlpa, key_in_piau_im_tlpa_plus,
        key_in_piau_im_poj, key_in_piau_im_bp, key_in_piau_im_bpm2,
        key_in_piau_im_ipa ]
```

> ⚠️ **上例寫法有誤，請勿沿用**，原因：
>
> 1. 缺少最外層的 `patch:` 鍵。Rime 只會讀取客製檔中 `patch:` 節點底下的內容並套用合併，沒有 `patch:` 包住的鍵值，部署時會被完全忽略、不會生效。
> 2. 直接整批改寫 `switches/options` 的順序，但沒有同步改寫對應的 `states`。依 `huan_ciat_tps.schema.yaml` 第 51-52 行的註解，`options` 與 `states` 必須依「位置序號」一一對應，只調動 `options` 的順序會讓選單顯示的名稱與實際生效的選項錯位。
> 3. 例子中的 `key_in_piau_im_tlpa_plus` 在 `huan_ciat_tps.schema.yaml` 的 `options` 清單中並不存在（該清單只有 9 個項目：`sni, tps, tlpa, tlpa_zu_im, tl, poj, bp, bpm2, ipa`），是筆誤或誤植。

### 正確的客製寫法

若只是要把【漢字標音選項】的【預設值】，由【十五音】（索引 0）改成【台羅拼音】（索引 4），**不需要**、也**不應該**更動 `options`／`states` 的順序，只需要修改該 switch 的 `reset` 值即可：

```yml
patch:
  # switches 清單第 3 個項目（索引 2，從 0 起算：0=ascii_mode, 1=full_shape, 2=漢字標音選項）
  # options/states 對應索引：0=十五音, 1=方音符號, 2=台語音標, 3=台語音標注音,
  #                          4=台羅拼音, 5=白話字, 6=閩拼方案, 7=台語注音二式, 8=國際音標
  "switches/@2/reset": 4
```

- 檔名須為 `huan_ciat_tps.custom.yaml`，且**整個內容都要放在 `patch:` 節點之下**，才會在部署（deploy）時被合併進 `huan_ciat_tps.schema.yaml`。
- `switches/@2` 的 `@2` 是 list 索引語法（與 `rime.lua` 第 303-306 行讀取 `switches/@i/options/@reset` 使用的語法一致），用來鎖定 `switches` 清單中「沒有 `name`、只有 `options`」的那一項；由於此類項目沒有唯一鍵可用，只能以位置索引定位。
- 只改 `reset`，保留原本 `options`／`states` 的順序與對應關係不變，避免選單顯示錯位。
