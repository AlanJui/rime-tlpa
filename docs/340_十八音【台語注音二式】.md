# 340_十八音【台語注音二式】需求規格書

## 摘要

### 方案識別

- schema_id: tsap_peh_im_bpm2
- name: 十八音【台語注音二式】
- dictionary: ji_khoo_bpm2
- prism: tsap_peh_im_bpm2（與 phing_im_bpm2 共用字典、各自編譯）


### 輸入方式（與十八音台羅版相同）

- 順序：聲 + 韻 + 調
- 調號：; - _ \ / [ ]，7＝促聲通配，*＝舒聲通配
- 候選註解：bbor5 [門高五]（每個漢字配兩欄【漢字標音】；左欄：台語注音二式，右欄：十八音）
- 預設上屏標音：台語注音二式

## 辭彙解釋

- 【BPM2】：表【台語注音二式】。
- 【十八音】：表【十五音】之改良版，新增：n【耐】、m【毛】、ng【雅】。

---

## 需求規格

### 特色

- 可打台羅寫法：tshong/ → cong⁵（床），ho/ → hor5（何）。
- 舒聲韻接促聲調（4/8/&），自動改正成促聲韻：bun[ → but⁴（不）。

### 聲母與韻母對映

台語注音二式與台羅拼音極相似，故以【對映關係】，說明兩者之異同處，條列如下：（參考 phing_im_bpm2）。

|台羅|注音二式|例子|
|----|--------|----|
|b / p / ph|bb / b / p| 無 bbor5、邊 b、頗 p|
|g / k / kh| gg / g / k| 語 gg、求 g、氣 k|
|ts / tsh |z / c |床 cong5|
|o / io / ik / iok |or / ior / iek / iook |好 hor2、益 iek4|


【測試查核重點】

- bbor/ → 無　bbor5 [門高五]
- cong/ → 床　cong5 [出公五]
- but[／bun[ → 不　but4 [邊君四]
- hor\ → 好　hor2 [喜高二]
- but7 → 同時出 4／8；bbor* → 同時出 2／5／7

### 聲母+i特殊處理

在【台羅拼音】，聲母： z, c, s, j ，其後接【韻母】，若韻母之首字為 i ，前面聲母仍不變。

但【台語拼音二式】聲母： z, c, s, zz ，其後接【韻母】，若韻母之首字為 i ，前面聲母需改為：j, ch, sh, jj。

當使用者輸入有錯，輸入方案之處理作業，將自動更正：

|誤打|自動更正|實測|
|----|--------|----|
|zi |ji |zi\ → 編輯列 ji²，出「只」等|
|ci |chi |cit[ → chit⁴，出「七」|
|si |shi |si- → shi⁷|
|zzi |jji |zzi\ → jji²（子）；zzit] → jjit⁸（日）|

### 鼻韻母處理

強化 nn (ⁿ) ：【鼻韵母符號】處理：以下之變更處理原則為：在鍵入拼音字母之時，【輸入框】之顯示，將nn改用(ⁿ)代，視覺之辨視可較為快速、容易。但因【台語注音二式】不似【白話字】有【nn 改 ⁿ 代】的規範，故而【候選清單】所顯示之【台語注音二式】拼音字母仍維持不變。

1. 遇 nn 用 ⁿ 代。【ⁿ】為【鼻韵母符號】。
    【鍵入】：【nn】，【輸入框】：顯示【ⁿ】代。【候選清單】則不變。

    《例》：漢字【腔】，BPM2【kiunn1】。【鍵入】：【kiunn】，【輸入框】：顯示【kiuⁿ】代。【候選清單】顯示【kiunn1】。

2. 支援【鼻韵母符號】前置輸入用法。如【閩拼方案】，認為【鼻韵母符號】應顯示在前，如此為之，人們才比較容易【事先】察覺n之後的拼音字母，當以鼻音發聲。如：【kiunn1】=【kiuⁿ】=【kⁿiu】。使用者看到 ⁿ 之後的 iu ，會立即意識到當用鼻音為韻母【iu】發聲。

    - 鼻韻母：ann, inn, enn, oonn（台羅拼音：onn）, ainn, iann, iunn, ionn, uann, uainn, iaunn。
    - ann=nna=ⁿa
    - inn=nni=ⁿi
    - enn=nne=ⁿe
    - oonn=nnoo=ⁿo
    - ainn=nnai=ⁿai
    - … 請類推

3. 支援鼻韻母符號輸入按鍵【N】。

鍵入【N】，等同輸入【nn】。故【輸入框】顯示鼻韻母符號：【ⁿn】。再次強調：【候選清單】中之拼音字母顯示無須跟著變更。
